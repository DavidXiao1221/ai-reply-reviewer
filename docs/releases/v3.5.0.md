# Reply Review v3.5.0

首个 GitHub 正式发布版本，沿用已验证的本地 v3.5.0 功能与安装包。

## 本版功能

- ChatGPT、Gemini、Perplexity、Grok：侧栏打开后自动审阅最新完整回答，生成短结论、关键要点和必要的轻量简评。
- 普通网页：识别文章、新闻与长文，自动生成主旨、阅读地图和少量有依据的提醒。
- 原句定位与对照、结果复制、网页自动导读开关、暂停、手动粘贴与右键选区审阅。
- 每次一次 DeepSeek 请求；失败不自动重试，复制与定位不发起模型调用。

## 下载与安装

下载附件 **`reply-reviewer-3.5.0-chrome.zip`**，解压后在 `chrome://extensions` 启用开发者模式，选择“加载已解压的扩展程序”，加载直接包含 `manifest.json` 的目录。

最低 Chrome 版本：116。设置自己的 DeepSeek API Key，并允许网站访问。升级后刷新相应网页。

GitHub 自动附带的 Source code 文件是源码，需要自行构建；请勿直接当成扩展安装目录。

- 从待发布文件单独导出干净目录，执行 `npm ci`、类型检查与生产构建，通过；公开固定测试 **27 个文件、415 项全部通过**。私人回放材料及依赖这些材料的测试保留在本机。

- 本次首发准备未调用真实 DeepSeek API。模型效果和站点所有动态布局不由固定测试保证。

## 已知边界

- 仅分析读取到的文字，不读取图片、附件或引用网页，不代表联网事实核验。
- 不能提取所有应用和信息流；动态布局、未展开正文或访问限制可能影响识别。
- 短于 300 字符的普通网页正文可能不触发；超过 30,000 个 JavaScript 字符的输入会明确拒绝。
- 缓存只在当前侧栏会话内有效；重开侧栏或主动重新生成可能再次产生 API 请求。
- X 长文适配有结构测试，但历史匿名页面访问受限，不能据此声称已覆盖所有登录状态。

本次冻结 v3.5.0。竞品研究中的阅读路线增强、持久恢复、图表理解和外部核查属于后续讨论，不包含在此版本中。
